# Parsing examples
- `Debug histogram.ipynb`: parse and plot a debug histogram from a Bridgeport detector.
- `health data.ipynb`: plot health data extracted from EXACT or IMPRESS detector health packets.
- `Nominal IMPRESS data.ipynb`: parse and plot IMPRESS spectrogram data (123 energy bins, 32 Hz frame rate)
- `NRL list mode.ipynb`: parse and plot EXACT NRL list mode data which has been decoded using `decode-exact-science` tool.
